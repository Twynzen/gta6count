# 👮 Enemy Sound Effects

Place all enemy-related sound effects here in both MP3 and OGG formats.

## Required Files:

### Cop Sounds
- `sfx_cop_spawn.mp3` / `.ogg` (0.5-0.8s)
- `sfx_cop_alert.mp3` / `.ogg` (0.3-0.5s)
- `sfx_cop_death_01.mp3` / `.ogg` (0.4-0.7s)
- `sfx_cop_death_02.mp3` / `.ogg` (0.4-0.7s)
- `sfx_cop_death_03.mp3` / `.ogg` (0.4-0.7s)

**Cop Death Volume**: -12dB to -9dB (frequent sound)

### Boss Sounds
- `sfx_boss_spawn.mp3` / `.ogg` (1.5-2.5s)
  - **Style**: Dramatic, unique, sirena + sting
  - **Volume**: -6dB to -3dB

- `sfx_boss_hurt.mp3` / `.ogg` (0.2-0.4s)
  - **Style**: Metallic/heavy impact
  - **Volume**: -9dB to -6dB

- `sfx_boss_death.mp3` / `.ogg` (1.5-2.5s)
  - **Style**: Dramatic explosion
  - **Volume**: -3dB to 0dB

## Specifications:
- **Format**: MP3 (128-192kbps) + OGG
- **Sample Rate**: 44.1 kHz
- **Channels**: Stereo

See `../../SOUND_ASSETS.md` for complete specifications.
