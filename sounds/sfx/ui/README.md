# 🖱️ UI Sound Effects

Place all UI-related sound effects here in both MP3 and OGG formats.

## Required Files:

### UI Interactions
- `sfx_ui_click.mp3` / `.ogg` (0.05-0.1s)
  - **Style**: Clean click sound
  - **Usage**: Button clicks
  - **Volume**: -18dB to -15dB

- `sfx_ui_hover.mp3` / `.ogg` (0.03-0.08s)
  - **Style**: Subtle blip/beep
  - **Usage**: Mouse hover over buttons
  - **Volume**: -24dB to -21dB

### Game Events
- `sfx_robbery.mp3` / `.ogg` (0.5-1.0s)
  - **Style**: Alarm, caja registradora, cristal roto
  - **Usage**: When robbing the store
  - **Volume**: -9dB to -6dB

- `sfx_wave_start.mp3` / `.ogg` (0.5-1.0s)
  - **Style**: Alarm/sirena
  - **Usage**: Every 8 seconds when new wave starts
  - **Volume**: -12dB to -9dB

## Specifications:
- **Format**: MP3 (128-192kbps) + OGG
- **Sample Rate**: 44.1 kHz
- **Channels**: Stereo

See `../../SOUND_ASSETS.md` for complete specifications.
