# 💣 Weapon Sound Effects

Place all weapon-related sound effects here in both MP3 and OGG formats.

## Required Files:

### Bomb Sounds
- `sfx_bomb_place.mp3` / `.ogg` (0.3-0.5s)
  - **Style**: Electronic click/beep
  - **Volume**: -12dB to -9dB

- `sfx_bomb_tick.mp3` / `.ogg` (0.1s)
  - **Usage**: Loops every 0.5s while bomb is active
  - **Pitch**: Increases as explosion approaches
  - **Volume**: -15dB to -12dB

- `sfx_bomb_explosion.mp3` / `.ogg` (1.0-2.0s)
  - **Style**: Large satisfying explosion
  - **Volume**: -3dB to 0dB (loud)

## Specifications:
- **Format**: MP3 (128-192kbps) + OGG
- **Sample Rate**: 44.1 kHz
- **Channels**: Stereo

See `../../SOUND_ASSETS.md` for complete specifications.
